\chapter{Hướng dẫn tái lập và đối chiếu source}

\section{Các lệnh tái lập}
Thực hiện từ thư mục gốc repository. Các lệnh dưới đây dùng thư mục
\src{reports/artifacts/demo} cho kết quả mẫu để phân biệt với graph store.
Nếu sử dụng virtual environment, thay \texttt{python3} bằng
\src{.venv/bin/python}.
\begin{lstlisting}
python3 main.py cokb_build \
  --input examples/icd_mapping_sample.json \
  --output reports/artifacts/demo

python3 main.py cokb_query \
  --store reports/artifacts/demo \
  --code K05.1 --system ICD10WHO

python3 main.py cokb_explain \
  --store reports/artifacts/demo \
  --mapping-id mapping-k05-1-da0b-y

python3 main.py cokb_eval \
  --output reports/artifacts/evaluation.json

python3 -m unittest discover -s tests -v
\end{lstlisting}
Script \src{reports/scripts/collect_evidence.py} thực hiện thu thập
kết quả dùng trong báo cáo bằng một lệnh:
\begin{lstlisting}
python3 reports/scripts/collect_evidence.py
\end{lstlisting}
Script chỉ ghi vào \src{reports/artifacts/}; không thay đổi ontology,
rules, gold hoặc graph store gốc.

SHACL là kiểm tra bổ sung sau khi cài dependency:
\begin{lstlisting}
python3 -m pip install -e '.[validation]'
python3 main.py cokb_shacl \
  --store reports/artifacts/demo \
  --report reports/artifacts/shacl_report.ttl
\end{lstlisting}
Lệnh này phải được chạy và ghi nhận riêng trước khi thay trạng thái
SHACL trong kết quả thực nghiệm.
